# WK Design — копия исходного сайта

Полная статическая копия публичных страниц http://wk-design.ru/, снятая 2 октября 2026 года.

Сайт: https://romans7997.github.io/wk-design-mirror/

## Страницы

- `index.html` — главная, ассортимент, хиты продаж, история бренда.
- `about.html` — история бренда, оригинальное видео, преимущества.
- `contacts.html` — контакты и реквизиты.
- `policy.html` — политика конфиденциальности целиком.

## Сохранённые ресурсы

Оригинальные HTML, CSS, JavaScript, изображения, логотипы, SVG-спрайт, favicon и видео. Фотографии, скрипты и видео сохранены без перекодирования. Шрифт Manrope v20 с начертаниями 200–800 и всеми шестью языковыми наборами хранится локально; Google Fonts для отображения сайта не требуется.

Внешние ссылки на Ozon, Wildberries, email и телефон сохранены.

## Адаптация для GitHub Pages

Изменены только ссылки `href="/"` на `href="./index.html"` и импорт Google Fonts на локальный `css/fonts.css`. Добавлен `.nojekyll`. Исходный дизайн, тексты, адаптивная верстка и интерактивность сохранены.

GitHub Pages публикует корень ветки `main`. Сборка и npm не требуются.

Локальный просмотр:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Проверка охватывает все четыре страницы на размерах 1440×900 и 390×844, включая полную прокрутку, меню, переходы, карусель, воспроизведение и паузу видео. Тексты, размеры заголовков, секций и высота страниц совпадают с оригиналом. Подробности: `design-qa.md` и `mirror-audit.json`.

Содержимое опубликованной копии можно изменять независимо от исходного домена.
